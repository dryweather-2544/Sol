S6 notes: the brief says to write linear palette colours (`srgb_to_linear`). I did NOT convert: the existing profile palettes (for example `Color(0.28, 0.36, 0.2)`) are already written straight into vertex colours, which Godot treats as linear unless `vertex_color_is_srgb` is set (it is not; this is from memory of the Godot docs, not run here), so converting would darken every world against today's look. Heights, normals, indices and collision are untouched; only the colour alpha and RGB scaling formula changed (alpha was an unused `0.9 + 0.1 * patch`; now it is the slope weight, and RGB is scaled the same as before). The steep weight has been unit-tested as a curve and on a flat planet only, never on real hills. The new shader gets its `.uid` on first import on the Mac.
