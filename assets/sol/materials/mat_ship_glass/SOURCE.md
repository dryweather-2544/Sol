# mat_ship_glass
Parameter-only StandardMaterial3D (no textures): alpha-blended, albedo #7A8FA3 at alpha 0.06, roughness 0.05, specular 0.6.
Written by `lookdev/tools/make_param_materials.gd`. An optional 512² smudge-roughness texture is deferred.
Lookdev note: first attempt (alpha 0.14, lighter albedo) read as a milky grey wall; this is the toned-down version. Status: review.
