# mat_hull_nozzle

Procedural, original (no third-party input). Baked by `lookdev/bake/bake_hull_nozzle.gd`; deterministic (seeds 501-504).
Rebuild + validate: `lookdev/tools/build_material.sh mat_hull_nozzle 1.0 --wrap-u --uv` (`--uv` = mesh UVs, `uv1_triplanar` off, `uv1_scale` 1; `--wrap-u` = only the left/right wrap is a seam).
**Size 1024 x 1304** (the manifest's 512x1024 changed). The game's nacelle is a `CylinderMesh` top r 0.55 / bottom r 0.65 / height 2.4 [V `Sol/src/flight/ship_visuals.gd` l.181-189], at (±2.4, -0.3, 9.3), rotated (90, 0, 0); nose is -z [V l.4].
**UV layout probed** (`lookdev/tools/probe_cylinder_uv.gd`): the SIDE uses u 0..1, **v 0..0.5**; both CAPS use v 0.5..1. So the side is the top half of the PNG: rows 0..651 = 1024 x 652 px (~272 px/m on the mean circumference 3.77 m, 2.4 m long); rows 652..1303 are the cap region (dark soot, metallic 0).
**Which end is the exhaust:** the nacelle is at the rear (+z), so the exhaust end faces +z. A render with a marker sphere at +z (scratch diagnostic, not kept) showed that with rotation (90, 0, 0) the texture rows near **652** land at +z and row 0 at the nose side. That contradicts what the probe and the rotation maths predict (v 0 at mesh y +1.2, +y -> +z), and the cause was not found. The map is baked to the render, which is what the game will show: **exhaust lip = bottom of the side region (row ~652), cold end = row 0**. Integration should confirm with one screenshot; if the hot end is wrong there, mirror `uv1_scale.y = -1` / `uv1_offset.y = 0.5`, do not re-bake.
Content: spun steel (`#8C8F93`, machining marks run around the nozzle), ring seams every ~0.6 m, heat tint steel -> straw `#C58A3E` -> purple `#6B4A7A` toward the lip, ragged soot band at the lip (albedo ~0.17, **metallic 0**, roughness 0.9), everything else metallic 1 (binary; mid-range 0 %). Direction of the gradient (purple hottest, at the lip) is my reading of ART_DIRECTION's `#6B4A7A -> #C58A3E`.
Validation 2026-10-18: CHECK PASS --wrap-u (albedo luminance 37..148, metallic mid-range 0.00 %, unit normals, u-wrap seam ratios 0.46 / 0.65 / 0.41). The v direction is not tiling by design.
Integration (I4): `mat_hull_nozzle.tres` replaces the nacelle material; exhaust glow stays the code's job (the nacelle uses `_glow_material` today). Review shots: `lookdev/shots/mat_hull_nozzle_{game_light,proposed_light,seam}.png` (`seam` = nacelle spun 180 deg to show the u seam).
